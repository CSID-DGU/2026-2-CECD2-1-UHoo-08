## 2. 합성 데이터를 만든 방법

생성 기록은 모두 `eval/prompts/`에 있다. 어떤 지시로 무엇을 만들었는지 이 파일들로 확인한다.

| 기록 | 만든 데이터 | 방법 |
| --- | --- | --- |
| `personas_v1.md` | 페르소나 20명 | Claude Code가 상품 마스터를 읽기 전용으로 조회해 고정 시드(20261114)로 뽑았다 |
| `router_queries_v1.md` | 라우터 128건 | Claude에게 질의를 만들게 하고 사람이 훑어 걸렀다 |
| `scenario_v1.md` | S2 60건, S1 20건 | 페르소나와 상품 마스터로 만들었다. 고정 시드 20261114 |
| `scenario_s7_v1.md` | S7 20건 | 페르소나와 상품 가격, 제품 종류로 만들었다 |
| `feedback_v1.md` | 피드백 세션 20건, 골든셋 20건 | 페르소나와 S2 질의에 피드백 순서를 붙였다 |
| `home_env_v1.md` | HOME_ENV 10건 | 페르소나와 보유 제품 특징에 가짜 환경 요약을 붙였다 |
| `home_routine_v1.md` | HOME_ROUTINE 7건 | 페르소나의 보유 제품(별점, 개봉일)에 궁합 쌍을 붙였다 |

검증 방법은 이렇다.

- `python -m eval.validate`: DB 없이 형식을 본다. id 접두어, `split`, `source`, `check`, 보유 제품의 `usage_type` 등을 검사한다
- `python -m eval.validate --db`: 참조한 `product_id`가 상품 마스터에 실제로 있는지까지 본다. 없는 id가 섞이면 보유 제품이 없는 사람처럼 동작하기 때문이다
- 2026-11-18에 두 검사 모두 통과했다. 참조하는 상품 id는 102개다
- 프롬프트와 규칙은 dev를 보고만 고치고, 수치는 test로 낸다. 한 번 test로 정한 레코드는 dev로 바꾸지 않는다

## 3. 잘 된 것과 안 된 것

### router

- 잘 된 것: 카테고리, 예산, 환경, 가성비, 추천 기준 추출은 test에서 모두 맞았다
- 실패 사례
  - **router-g-0310** "3만원 이하만 보여줘": 조건 수정인데 새 검색으로 읽었다. 직전 결과가 있다는 사실을 질의 해석이 모른다. 2026-11-14에 직전 결과가 있으면 조건 수정으로 보내는 규칙을 넣었고, 아직 다시 재지 않았다
  - **router-g-0109** "메디힐 수분크림 대신 쓸 만한 거 추천": 상품 평가인데 검색으로 읽었다. "X 대신", "X 말고"가 기준 상품을 놓고 대체를 찾는 말이라는 것이 프롬프트에 없다. 아직 고치지 않았다

### scenario

- 잘 된 것
  - S1 상품 평가는 6 / 6이다
  - 추천 엔진이 켜는 점수 항목(`popularity`, `budget_fit`, `query_fit`)은 기대한 질의에서 모두 들어갔다
  - 실패 15건 중 추천 엔진 코드가 틀려서 난 실패는 없다. 14건은 B, C 부품이 아직 없어서 났다
- 실패 사례
  - **scenario-g-0033** "요즘 날씨에 맞는 선크림": 환경 점수 `env_fit`과 ENV 배지가 없다. 환경 점수 항목(B)이 없어서다. 가성비 질의의 `value_signal`(C)도 같은 이유로 빠졌다(7건)
  - **scenario-g-0094** "무향 제품으로, 민감한 피부에도 괜찮은 제품으로": "보습 크림" 결과에 종류가 비어 있는 '라네즈 크림 스킨 미스트'가 들었다. 상품 추출의 종류 허용값에 미스트가 없어 종류가 비었고, 검색 필터는 종류를 모르는 상품을 남긴다
- 보유 제품 단계(B)가 없어 보유 제품 빼기, 홈 환경의 덮임 판정, 홈 루틴 실행이 모두 확인되지 않았다(7건). `must_exclude` 25건 중 22건 통과는 보유 제품이 우연히 후보에 들지 않은 결과라 지표로 쓰지 않는다

### 피드백 반영

- 잘 된 것: "너무 비싸요"를 누르면 저렴한 상품의 순위가 오르고, 되돌리면 원래 결과로 돌아간다. 6건 모두 통과했다
- 실패 사례: 없다. 다만 test가 6건뿐이고, 보유 제품, 환경 점수, 가성비 점수가 없는 상태에서 쟀다

## 4. 다음 조치
