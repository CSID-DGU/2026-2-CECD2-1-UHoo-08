# 광고 판별 골든셋 생성 (v1)

`eval/golden/trend/ad_v1.jsonl` 100건을 만든 방식이다.
합성 데이터가 아니라 실제로 수집한 인스타 캡션에 광고 여부를 붙인 것이다.

## 원본

`influencer_posts` 에 쌓인 게시물 235건 중 캡션이 있는 230건.
22개 계정, 게시일 2026-09-30 ~ 2026-10-29 (수집 배치 첫 실행분).

## 뽑은 방식

무작위로 뽑으면 거의 다 광고 표기가 없는 일상 글이라 판별이 어려운 경우가
몇 건 안 남는다. 그래서 캡션을 세 층으로 나눠 따로 뽑았다.

```python
# 광고·제공 표기
DIS = r'#\s*(유료)?광고|[*(\[]\s*광고|광고\s*[*)\]]|^\s*광고|광고\s+@?[a-z0-9_.]+|#\s*협찬|협찬|제품\s*제공|원고료|유료\s*광고'
# 아니라고 밝히거나 돌려 말하는 표현
NEG = r'광고\s*(아님|아니|x|X)|내돈내산|직접\s*구매|광고를\s*포함'
# 표기 없이 상업적인 신호
COM = r'공구|공동구매|할인\s*코드|쿠폰|프로필\s*링크|링크.{0,15}(보내|발송|드려)|구매\s*링크|특가|오특|최종\s*[\d,]+원|\d+\s*%\s*할인|이벤트|증정'

ambiguous = NEG 에 걸리거나, COM 에 걸리는데 DIS 에는 안 걸림
disclosed = 그 밖에 DIS 에 걸림
none      = 셋 다 안 걸림
```

| 층 | 전체 | 뽑은 수 | 방식 |
| --- | --- | --- | --- |
| ambiguous | 27 | 27 | 전부 |
| disclosed | 64 | 30 | 계정당 최대 3건 |
| none | 139 | 43 | 계정당 최대 3건 |

순서는 `random.Random(20261102)` 로 섞었다. 한 계정이 몰리면 그 계정의 표기
습관만 맞추는 규칙이 나오기 때문에 계정당 수를 막았다. 결과적으로 21개 계정이
들어갔다.

층 이름은 판정 근거가 아니라 뽑을 때만 쓴 구분이다. `none` 43건 중 9건은
실제로 광고였다 (본인 브랜드 홍보 7, "무료 제공"·"#🎁" 같은 처음 보는 표기 2).

## split

층마다 섞은 뒤 번갈아 `dev`, `test` 를 붙였다. 세 층이 양쪽에 고르게 들어간다.

| | 광고 | 아님 |
| --- | --- | --- |
| dev | 29 | 22 |
| test | 29 | 20 |

## 정답을 붙인 방식

1. Claude 가 100건을 읽고 판정 초안과 근거 메모를 붙였다.
2. 초안을 붙이다 기준이 갈린 경우(21건)를 사람에게 물어 아래 기준을 정했다.
3. 사람이 100건 전부를 캡션과 함께 보고 확인했다. 바뀐 건은 없었다.

## 판정 기준

`is_ad` 하나로 판정한다. 경제적 이해관계가 있으면 광고다.

**광고**
- 유료광고·협찬 표기: `#광고` `*광고` `(광고)` `[광고]` `#유료광고`, 문장 끝의 `광고 @브랜드`
- 제품제공·단순선물제공·"제품 무료 제공 (노출 의무 없음)"
- 광고 제품과 아닌 제품이 섞인 게시물. 범례형("📘 직접 구매 / 📗 제품무상제공 / 📙 유료광고")에서
  제공·광고 아이콘이 붙은 제품이 하나라도 있으면 광고
- 인플루언서 본인 브랜드 홍보. 어느 계정이 어느 브랜드를 가졌는지는
  `data/influencer_accounts.json` 의 `owned_brands` 에 적는다
- 공구, 할인 링크, "댓글 달면 링크 보내드려요" (어떤 링크인지 몰라도)
- 표기 없는 상세 홍보(기획세트·할인가 안내), 제품 경품 이벤트

**광고 아님**
- 제품 언급이 없는 게시물 (본인 브랜드 계정의 인사, 신상 티저 등)
- 홍보 문구 없이 제품 태그·사용 제품 크레딧만 있는 게시물
- "(광고 아님)", "#내돈내산" 으로 밝힌 게시물

`(이벤트)#광고` 처럼 광고 표기가 있으면 본문에 "내돈내산"이 있어도 광고다.
본문의 내돈내산은 예전에 산 이야기였다.

## 레코드

```json
{"id": "trend-g-0001", "split": "test", "source": "real",
 "tags": ["disclosed", "disclosure"], "note": "",
 "input": {"post_id": 1, "username": "leojmakeup", "caption": "#광고 제가 너무 사랑하는 ..."},
 "expected": {"is_ad": true}, "check": "exact"}
```

- `input.username` 은 `owned_brands` 판정에 필요해서 넣었다.
- `tags` 의 첫 값은 뽑을 때의 층, 나머지는 판정 근거다. 규칙이 어느 유형에서
  틀리는지 볼 때 쓴다.
  `disclosure` `gifted` `own_brand` `affiliate` `event` `undisclosed` `mixed` `legend`
  `negation` `product_credit` `brand_tag` `teaser` `no_product`
- 캡션은 수집한 원문 그대로다. U+2028 같은 줄 구분 문자가 들어 있어 JSON 에서는
  ` ` 로 적었다. 그대로 두면 `str.splitlines()` 가 한 줄을 여러 줄로 자른다.
